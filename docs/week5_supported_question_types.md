# Week 5 Supported Question Types

## Supported
1. device_problem_trend
   - Example: Which device problem types appear most often in the latest year?
   - Example: What device problems are trending highest in the data?

2. manufacturer_summary
   - Example: Which manufacturers have the highest event counts in the latest year?
   - Example: Show manufacturer-level summaries for the most recent year.

3. report_field_help
   - Example: What does this FDA reporting field mean?
   - Example: What source information is likely needed for this section?

4. reporting_workflow_help
   - Example: How do I report a medical device problem?
   - Example: What is the difference between MedWatch and mandatory MDR reporting?

## Not Yet Supported
- patient-level risk prediction
- automatic report completion
- automatic report submission
- free-form forecasting questions
- multi-step reasoning across all FDA source families
